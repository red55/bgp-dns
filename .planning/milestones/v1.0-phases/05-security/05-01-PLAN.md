<objective>
Harden the daemon's gRPC admin channel end-to-end: make the Unix socket owner-only (mode 0600, SEC-01) and put a uniform server-side validation gate in front of every RPC while keeping the per-handler nil checks authoritative (SEC-02).

This is the tracer plan for Phase 5: it is the thinnest vertical cut through the most load-bearing requirement (socket permissions = the sole auth mechanism for the entire CLI control plane), delivered production-quality (real Serve() path, real listener, committed), with the adjacent SEC-02 validator wired into the same function. Expansion plans build outward from this hardened channel.

Purpose: A local non-owner must not be able to read/write the control socket (clear-cache, reload-list), and malformed RPC traffic (nil request/stream) must fail fast with InvalidArgument instead of reaching handler logic.
Output: chmod'd socket + unified interceptor gate, both covered by automated tests.
</objective>
