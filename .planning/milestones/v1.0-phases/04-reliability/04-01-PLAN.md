<objective>
DNS query timeout + O(n) set difference.

Purpose: Two independent reliability fixes with disjoint file sets. (A) Every DNS query currently goes through package-level `dns.Exchange`, which constructs a zero-valued client per call with an implicit 2s library default timeout that operators cannot tune — replace with a per-resolver cached `*dns.Client` whose cumulative `Timeout` comes from a new flat `Dns.Timeout` config field (default 5s, validated 3–30s). (B) `utils.Difference()` uses nested-loop O(n²) scans on the DNS-answer churn hot path (called twice per cache upsert) — rewrite internals to map-based O(n) while preserving the exact two-pass symmetric return shape, plus add its first-ever unit tests.

No external behavior change: same queries flow, same BGP operations fire; only failure timing becomes operator-configurable and set-diff cost drops.

Output: Configurable DNS timeout wired end-to-end, O(n) Difference with unit tests, full suite green.
</objective>
