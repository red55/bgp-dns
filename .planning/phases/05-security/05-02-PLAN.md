<objective>
Filter DNS query types for LISTED domains: only A, AAAA, and HTTPS are served; every other qtype against a listed domain is answered REFUSED without touching upstream. Unlisted domains retain fully transparent forwarding of any qtype.

Purpose: Listed domains exist to be cached-and-announced (IPv4 A). Serving arbitrary qtypes into that pipeline creates cache entries the BGP announcer never uses and enlarges the attack surface of the intercept path, while silently consuming upstream budget. REFUSED (not NXDOMAIN) tells clients the question was policy-denied, not that the name doesn't exist — and it prevents client-side negative caching of bogus non-existence.

**Decision D-05-P5 (adopting research recommendation OQ-2):** denied-qtype reply code is dns.RcodeRefused (=5). Alternative NXDOMAIN rejected because it conveys false semantics (name does exist) and poisons client negative caches. Recorded here per planning instruction since no CONTEXT.md exists.

**Known accepted asymmetry (adopting research recommendation OQ-1):** AAAA is SERVED but NEVER ANNOUNCED — BGP announcement stays IPv4-A-only (matches QWEN.md architecture). This is deliberate product state, not a gap; no announce work is scheduled in this phase.

Expansion task building outward from the Phase 5 tracer (the hardened control channel) into the data plane.
</objective>
