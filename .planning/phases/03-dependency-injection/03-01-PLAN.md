| T-03-02 | Information Disclosure | logger injection bypass | mitigate | Explicit *zerolog.Logger parameter in NewLoop and newResolvers — no log.L() fallback in constructors |

| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | N/A for Go modules — all deps verified via go list -m all |
