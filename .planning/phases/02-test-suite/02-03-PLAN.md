**Test setup (shared across E2E tests):**

2. Create a cache with real resolvers pointing to a fake DNS server
3. Register a domain in the cache's mux
4. Start the fake DNS server returning controlled responses

**Helper — setup E2E environment:**
```go
func newTestE2E(t *testing.T) (*cache, *bgpSrv, string) {
    t.Helper()
    initTestLogger()
    
    // 1. Create fake DNS server
    fakeAddr := setupFakeDNSServer(t, "example.com.", "10.0.0.1")
    
    // 2. Create bgpSrv for reference counting
    bgpSrv := newTestBgpSrvForE2E(t)
    
    // 3. Create cache with resolver pointing to fake server
    l := zerolog.New(os.Stderr).Level(zerolog.WarnLevel)
    resolvers := newResolvers([]*net.UDPAddr{{IP: net.ParseIP("127.0.0.1"), Port: 0}})
    // Configure resolver addr from fake server
    c := newCache(100, time.Duration(60), resolvers, &l)
    
    return c, bgpSrv, fakeAddr
}
```

**Test scenarios (per D-10, D-11):**

1. `TestE2E_DnsQueryToCacheToBgp`:
   - Create cache with fake DNS server returning A record for "example.com." → "10.0.0.1"
   - Register "example.com." in cache mux (via c.register("example.com."))
   - Construct DNS query msg: `newTestMsg("example.com.", dns.TypeA)`
   - Call `c.resolve(w, msg, false)` with mock ResponseWriter
   - Verify: ResponseWriter received answer with IP "10.0.0.1"
   - Verify: `bgp.Advance()` was called with ["10.0.0.1"] (check ipRefCounter["10.0.0.1"] == 1)
   - Per D-11: Do NOT verify full BGP path attributes — just verify Advance() was called with correct IPs

2. `TestE2E_MultiDomainIPSharing`:
   - Register two domains ("example.com." and "test.com.") that resolve to same IP "10.0.0.1"
   - Query both domains
   - Verify: ipRefCounter["10.0.0.1"] == 2 (two domains sharing one IP)
   - Withdraw one domain (simulate domainlist change)
   - Verify: ipRefCounter["10.0.0.1"] == 1 (not removed yet)
   - Withdraw second domain
   - Verify: ipRefCounter["10.0.0.1"] == 0 or key deleted (remove called)

3. `TestE2E_CacheHitReturnsAnswer`:
   - First query: resolve "example.com." → cache miss, hits fake DNS server, caches result
   - Second query: resolve "example.com." → cache hit, returns cached answer WITHOUT hitting resolver
   - Verify: Second query response matches first query response
   - Note: This tests the cache.get() path in resolve() — if cache has entry, return it directly

**Per D-12:** Use shared test server pattern — one DNS server for all E2E tests, reset state between tests.

**Global state handling:**
- The E2E tests touch `_cache` and `_bgp` globals. To avoid interfering with other tests:
  - Each test creates its own cache instance via `newCache()` (not using global `_cache`)
  - For bgp tests, construct `bgpSrv` directly (not using global `_bgp`)
  - Do NOT set `_cache = c` in E2E tests — use the local cache instance directly
  - For `upsert()` which calls `bgp.Advance()`, this operates on `_bgp` global — we need to set `_bgp` in test setup

**Critical: bgp.Advance() operates on `_bgp` global.** To make E2E tests work:
- In test setup, create a `bgpSrv` and assign it to `_bgp`
- In test cleanup, set `_bgp = nil` to restore state
- This allows `upsert()` → `bgp.Advance()` → `_bgp.Operation()` to work correctly

**Important:** Do NOT use `t.Parallel()` for E2E tests — they modify global state (`_bgp`).
